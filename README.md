## البنية التقنية والأتمتة (DevOps & SEO)

- **الواجهة الأمامية المربوطة بـ GitHub API:** `index.html` (بالإضافة إلى مشروع React + Vite الكامل في `src/`) تجلب قائمة الملفات وروابط الإصدار تلقائياً من:
  - `https://api.github.com/repos/aboanasanam42-cpu/Shopeapp/contents?ref=main`
  - `https://api.github.com/repos/aboanasanam42-cpu/Shopeapp/releases/latest`
- **خريطة الموقع ومحركات البحث:**
  - `sitemap.xml` و`robots.txt` موجهة لعنوان النشر الرسمي `https://dr-malik-alrumamh-store.netlify.app/`.
  - بيانات مهيكلة كاملة `JSON-LD` (`OnlineStore`, `WebSite`, `Product`) مدمجة داخل `index.html`.
- **النشر والأتمتة السحابية:**
  - `.github/workflows/release.yml`: يقوم بنشر وتحديث أصول `Release v1.0.0` تلقائياً عند الدفع إلى الفرع `main`.
  - `scripts/release_automation.py`: سكريبت أتمتة متكامل لرفع الأصول وفحص الإصدار وتحديث ملفات الويب.
  - `netlify.toml`: إعدادات التوجيه والأمان للنشر المستمر على Netlify.
